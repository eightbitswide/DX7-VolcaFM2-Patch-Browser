# DX7-VolcaFM2-Patch-Browser

Created for myself for my Launchkey mk2 49key keyboard and my Korg Volca FM2. 

The "Release" .zip contains the index.html file and
I've also included a set of Sysex files which are a "de-duplication" set of patches.

This is simply the setup I wanted for myself.  If you find it useful, let me know.

* You can search and load patches from the browser.
* You can favorite the ones you like.
* You can adjust the parameters of the voice both on screen and with your attached keyboard.
* You can create a performance set of patches and switch patches quickly.
* Load the patch to your Volca with a sample chord to hear it.
* Load the patch to your Volca quietly.
* Download the Sysex patch file.
* Create a set of favorite set of 32 patches to load directly.

There are also some bookmarks at the bottom of the page to useful pages on the web.

Note: Requires a Chrome Browser to work correctly.  Give it access to Midi.

I'm hosting the server side with an installed copy of Apache2 running on Linux Mint.
Simply extract the files from the release .zip to your /var/www/html folder and you should be good to go.
